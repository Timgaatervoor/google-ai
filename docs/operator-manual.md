# Operator Handleiding (Run Biathlon De Haan)

## Sneltoetsen & Bediening
- **Startregistratie**:
  - Typ startnummer (bijv. `128`) + `ENTER` -> Toon controle -> `ENTER` registreert start.
  - Of gebruik Mass Start per Wave voor groepstarts.
- **Finishregistratie**:
  - Veilige modus: typ startnummer + `ENTER` -> T1 timestamp wordt onmiddellijk bevroren -> controleer atleet -> `ENTER` bevestigt.
  - Snelle finishmodus: typ `128 ENTER 135 ENTER 102 ENTER` voor drukke finishstraten. Laatste 10 finishers worden direct getoond met `UNDO` knop.
  - `CTRL + Z`: Directe undo van de laatste actie.
- **Schietstand Operator**:
  - Selecteer je schietpost en ronde.
  - Typ startnummer atleet.
  - Tik op `0 MISSERS` t/m `5 MISSERS` of klik op de 5 interactieve schijven.
  - Bij dubbele registratie verschijnt een waarschuwingsmodal met opties Annuleren, Corrigeren of Nieuw toevoegen.
- **Operator Lock**:
  - Vergrendel het scherm voor specifieke posten zodat vrijwilligers niet per ongeluk naar instellingen of configuratie navigeren.
