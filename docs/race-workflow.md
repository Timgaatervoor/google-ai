# Wedstrijd Workflow (Race Workflow)

1. **Voorbereiding**:
   - Inschrijvingen importeren vanuit Stamhoofd (CSV/Excel).
   - Automatische startnummer toewijzing met ranges per categorie.
   - Waves genereren en startnummers/deelnemerslijsten printen.
   - Pre-Race System Check uitvoeren.
2. **Go Live**:
   - Event status overzetten naar LIVE.
   - Apparaten koppelen (Start, Finish, Schietpost A/B/C/D).
   - "Prepare Device for Offline Use" valideren op alle operators.
3. **Live Tijdregistratie**:
   - Mass Start per wave OF Individuele start met snelle bib-invoer.
   - Schietstand-operators registreren 0-5 missers of interactieve targets.
   - Finish-operator captureert finishtijden (Safe mode of Quick finish mode).
   - Live Command Center monitort finishers, lopers op parcours, schietbeurten en sync-status.
4. **Validatie & Publicatie**:
   - Resultaten validatie wizard (controleert DNS, DNF, ontbrekende schietbeurten).
   - Resultaten vastzetten (Draft -> V1 -> Official Lock).
   - Publicatie naar live klassement en PDF/CSV export.
